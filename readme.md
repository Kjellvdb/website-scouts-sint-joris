# Scouts Sint-Joris - Website

De officiële website van **Scouts Sint-Joris Aalst**, ontworpen om informatie te delen met leden, ouders en sympathisanten.

## 🚀 Over het project

Dit project bevat de broncode van de statische/dynamische website van de scoutsgroep, voorzien van eigen stijlen en fotomateriaal van de leidingsploeg.

## 🛠️ Tech Stack & Structuur

- **Frontend:** HTML5, CSS3, JavaScript
- **Stijlen:** Maatwerk stylesheets (`css/main.css`, `css/welkom.css`)
- **Media:** Geoptimaliseerde WebP afbeeldingen (`img/logo.webp`, leidingsfotos, etc.)
